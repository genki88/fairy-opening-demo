# 法芮 FAIRY　門店開店輔導 90 天平台　DEMO

從討論紀錄做出來的**可操作系統**（不是展示畫面）。前台（加盟主）＋後台（講師／輔導／驗收／陪跑／總部）兩端都在同一份資料上跑，核准一按，學員端立刻變。

---

## 怎麼打開

**雙擊 `index.html`**（或 `啟動DEMO.bat`）即可，不需要安裝任何東西、不需要網路。
建議用 Chrome 或 Edge 開。

## 兩端各有什麼

### 前台（加盟主／新人）
- **我的進度**：整體完成度環、目前階段、期限倒數、下一步建議、四類缺件清單、本階段任務
- **階段任務**：五個階段全展開，未開放的階段是鎖住的（看得到但不能做）
- **我的課程**：累計時數 vs 門檻、出席紀錄、可報名梯次、當天的掃碼報到
- **90 天陪跑**：開幕後才啟動，D+1／D+7／D+30／D+60／D+90 里程碑時間軸
- **AI 助理**：問「我缺什麼／下一步／時數夠嗎／為什麼被退回」，答案取自你真實的資料

### 後台（輔導與管理）
- **儀表板**：門店數、待我核准、進度落後、今日出席、各階段分布、最常卡關項目、需要關注的門店
- **待核准**：依角色只看自己該核的；核准 / 退回補件（退回要寫原因）
- **門店進度**：全門店列表（搜尋／階段／區域篩選、匯出 CSV）→ 點進單店看全貌與輔導歷程
- **今日簽到**：已報到／未到／缺席即時統計、現場報到條碼、講師可直接勾選出席
- **課程管理**：所有梯次、報名與出席率、新增梯次
- **階段與標準**：改核准角色、建議天數、時數門檻（改完立刻套用到所有門店判定）
- **人員與權限**：權限矩陣、一鍵以任一身分檢視
- **稽核紀錄**：誰在什麼時候核准／退回／報到，全部留痕

## 核心規則（這份系統的靈魂）

```
完成事項 → 送審 → 講師／主管審核 → 核准 → 才進入下一階段
```

- 學員**無法**自行勾選「已完成」——只能「送審」。
- 課程型任務也不例外：掃碼報到成立 → 系統自動送審 → **仍需講師核准**。
- 一個階段的任務全部核准、且訓練時數達門檻，下一階段才自動解鎖。
- 每一次核准／退回／報到都寫進稽核紀錄。

五個階段與核准人（可在後台改）：

| 階段 | 名稱 | 核准人 | 時數門檻 | 建議天數 |
|------|------|--------|---------|---------|
| 1 | 新人報到與基礎訓練 | 講師 | 18 小時 | 21 天 |
| 2 | 選址與店面評估 | 店務輔導人員 | — | 30 天 |
| 3 | 開店準備 | 店務輔導人員 | 36 小時 | 45 天 |
| 4 | 門店驗收與開幕 | 驗收主管 | — | 14 天 |
| 5 | 開店後 90 天陪跑 | 陪跑顧問 | — | 90 天 |

## AI 在這裡扮演什麼

**會做**：算出還缺哪幾項、給下一步具體動作與負責窗口、提醒逾期、產生進度摘要、解釋退件原因、幫總部點出落後門店與最常卡關項目。

**不會做**：不代替講師或主管核准、不自動標記任務完成、不修改出席與時數紀錄。

目前 DEMO 的回覆是**規則引擎**依真實資料組成的（所以數字都對得上），正式版可再接語言模型處理自由問答。

## 這份 DEMO 的限制（先講清楚）

1. **資料存在你這台電腦的瀏覽器裡**。換一台裝置打開會回到初始狀態，也不是多人共用的線上系統——你核准的，同事那邊看不到。
2. **沒有帳號密碼**，點身分卡就進去了。正式版要接真的登入。
3. **檔案上傳是示意的**，選了檔名但沒有真的存檔。
4. **掃碼報到是模擬的**，按「模擬掃描成功」代替真的開相機。
5. 想回到初始資料：後台 →「稽核紀錄」→ 右上角「重置 DEMO 資料」。

## 接下來要決定的事

1. **階段定義要不要照這五段走？**每階段的任務清單目前是依討論紀錄擬的，實務上該有哪幾項、誰核准，需要你們定案。
2. **18 小時／36 小時的課程怎麼對應到階段？**現在是第一階段 18 小時、第三階段再加 18 小時（合計 36）。
3. **90 天陪跑的回報節點**目前設 D+7／D+30／D+60／D+90，要不要改成月報或雙週？
4. **要不要做文件真上傳**（會需要儲存空間）與**真掃碼報到**（需要手機開相機＋HTTPS 網域）。
5. **正式版的帳號怎麼發**：加盟主一人一帳號，還是一店一帳號（多人共用）？

## 檔案結構

```
demo/
├─ index.html          全部樣式與版面（法芮色票在最上方 :root）
├─ js/
│  ├─ data.js          資料層＋業務規則（接真後端只要改這一支）
│  ├─ ui.js            共用元件（進度環、進度條、任務列、條碼）
│  ├─ front.js         前台五個頁面
│  ├─ admin.js         後台八個頁面
│  └─ app.js           路由、登入、身分切換
└─ assets/             法芮 Logo 四色版 + favicon
```

**品牌色**（取自法芮 CIS）：主色 `#4F2F2E`（Pantone 497C）／輔色 `#AA7D64`（Pantone 479C）／淺色 `#F6E9DB`。全部集中在 `index.html` 的 `:root`，要調色改那幾行就好。
